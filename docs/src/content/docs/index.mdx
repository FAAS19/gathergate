GatherGate is a self-hosted, open-source alternative to Content Snare and FileInvite. Collect client documents and structured details through passwordless magic links with deterministic validation, AES-256-GCM encryption at rest, automated reminders, and keyboard-first review in a single Node.js or Docker runtime.

- **Runtime**: Node.js `>= 22.13` (Node 24+ recommended for built-in `node:sqlite` and `node:crypto.argon2Sync`), 5 backend production dependencies, zero external database.
- **Zero telemetry**: GatherGate never phones home. Outbound network traffic happens only when you configure SMTP/Resend, S3/R2 storage, or webhooks.

## Architecture at a Glance

| Layer | Implementation |
| :--- | :--- |
| **HTTP API & SPA** | Hono (`@hono/node-server`) serving the built React 19 + Tailwind CSS v4 frontend |
| **Metadata Store** | Built-in `node:sqlite` in WAL mode (`DATA_DIR/gathergate.sqlite`) with versioned migrations |
| **Blob Storage** | Encrypted local files (`DATA_DIR/blobs`) or any SigV4 S3/R2/MinIO/B2 bucket (`aws4fetch`) |
| **Encryption at Rest** | Per-record HKDF-SHA256 + AES-256-GCM bound with authenticated additional data (AAD) |
| **Outbound Email** | Built-in Local Outbox (`console`), SMTP (`nodemailer`), or Resend HTTP API |
| **ZIP Export** | Streaming decrypted archive (`yazl`) with `summary.json` and canonicalised `files/` |
