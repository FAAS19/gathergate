GatherGate requires no external database, Redis, or message broker. Pick the runtime that matches your machine or server.

<Tabs>
  <TabItem label="npx (Node.js 24+)">
```bash
npx gathergate
```
Runs natively on Node.js `>= 22.13` (Node 24+ recommended), auto-loads `.env` from the working directory, and stores data in `./data` on `http://127.0.0.1:3080`. Useful CLI helpers: `npx gathergate doctor`, `npx gathergate setup --client claude-desktop`, and `npx gathergate mcp`.
  </TabItem>
  <TabItem label="Docker">
```bash
docker run -d \
  --name gathergate \
  -p 127.0.0.1:3080:3080 \
  -v gathergate_data:/data \
  ghcr.io/faas19/gathergate:latest
```
Multi-arch (`linux/amd64` and `linux/arm64`) non-root container image published from GitHub Actions.
  </TabItem>
  <TabItem label="Docker Compose">
```bash
git clone https://github.com/FAAS19/gathergate.git \
  && cd gathergate \
  && docker compose up -d --build
```
Hardened container defaults (`cap_drop: [ALL]`, `read_only: true`, `no-new-privileges:true`, bound to `127.0.0.1:3080`).
  </TabItem>
  <TabItem label="From Source">
```bash
git clone https://github.com/FAAS19/gathergate.git && cd gathergate
npm ci
npm --prefix client ci
npm run build
NODE_ENV=production HOST=127.0.0.1 PORT=3080 DATA_DIR=./data npm start
```
  </TabItem>
</Tabs>

## Verify the Server

Confirm the health endpoint returns HTTP `200`, or run the read-only CLI diagnostic:

```bash
curl http://127.0.0.1:3080/healthz
# {"ok":true,"service":"gathergate"}

npx gathergate doctor --url http://127.0.0.1:3080
```

## First-Run Setup

1. Open `http://127.0.0.1:3080` in your browser.
2. Complete the split-screen workspace onboarding (workspace name, operator email, password, and optional demo packs).
3. Inspect outgoing magic-link invites and 6-digit OTP codes inside **Local Outbox** (`/outbox`) before connecting SMTP or Resend.

:::caution[Production `MASTER_KEY`]
On first boot without `MASTER_KEY` set, GatherGate auto-generates a 32-byte key at `DATA_DIR/.master.key` so quickstarts work immediately. Before storing real client documents, move that value into your environment or secret manager and back it up separately from `DATA_DIR`.
:::
